# 版本记录

## 1.4.0 — 2026-08-12

- 新增《用户协议与数字资产使用声明》及首页页脚入口
- 公开仓库新增保留所有权利的专有许可证，明确公开可见不等于开源
- 明确禁止未经授权的转载、再发布、商业利用、模型训练、微调、评估、嵌入、RAG与数据集制作
- 公开署名统一为 MOIRAI / TenetJustin，并新增版权联系邮箱

## 1.3.0 — 2026-08-12

- 首页新增“安装到手机／电脑桌面”按钮，支持 Edge、Chrome 和 Android 直接触发 PWA 安装
- iPhone、iPad 或无法直接弹出安装提示的浏览器显示简明安装步骤
- 检测独立应用运行状态，已安装时显示“已安装到桌面”并避免重复安装

## 1.2.3 — 2026-08-12

- 提高首页循环滚动塔罗牌面的不透明度、饱和度与对比度
- 将循环牌面提升到柔化遮罩上方，使电脑与手机端卡面保持清晰，同时保留背景层次和滚动效果

## 1.2.2 — 2026-08-12

- 希腊神话桥梁改为按单牌、三牌、凯尔特十字分别生成综合神话线，不再逐牌拼接数据库说明
- 综合神话线体现牌阵位置、正逆位、核心矛盾、内外作用与条件性结果，并限制在 400 字以内

## 1.2.1 — 2026-08-12

- 修复首页及仪式开始前因牌阵尚未抽取却提前运行综合规则而产生的黑屏
- 牌阵未完整展开时返回安全的空解读状态，完成抽牌后才运行因果链、共同主题、优先级与行动规则

## 1.2.0 — 2026-08-12

- 单牌、三牌和凯尔特十字分别使用独立的本地因果链规则，不再把各位置解释简单拼接
- 新增共同主题分析，综合正逆位比例、大阿尔卡那比例、重复关键词及预设牌组关系
- 新增按牌阵位置排序的处理优先级，区分当前阻碍、深层原因、内外因素与结果复查
- 新增按问题类型生成的“直接行动、后续行动、调整原则”具体行动，不附加人为时间提示，全程不连接 AI 或第三方接口

## 1.1.1 — 2026-08-11

- 修复完成并保存一次仪式后，未刷新页面再次开始仪式仍保留上一轮问题、牌阵、净化、洗牌、切牌或抽牌状态的问题
- 所有新仪式入口统一先完整重置临时仪式状态；已保存的命运档案不受影响
- “版权与版本”新增服务器版本核对和 Git 构建提交标识
- 发布流程新增版本同步与版本递增检查

## 1.1.0 — 2026-08-11

- 新增 78 张牌完整 RWS 正逆位本地数据库
- 新增爱情、事业／学业、财富、人际、自我与综合问题分类
- 新增单牌、三牌与凯尔特十字位置规则及牌组组合关系
- 抽牌改用安全随机源，独立生成正逆位并防止重复
- 移除所有外部 AI 和第三方模型接口

## 1.0.0 — 2026-08-10

- 应用版本：`1.0.0`
- 资产版本：`greek-tarot-78-v1`
- 本地数据格式：`schema 1`
- 完整 78 张正面与 78 张专属解释背面
- PWA 安装、独立窗口与基础离线访问
- 本地档案、收藏及设置的统一导出、导入和删除入口
- 无账户、无数据库、无用户追踪、无内置 API Key

发布时更新 `package.json`、`public/version.json` 和本文件。构建脚本会把版本同步到 Service Worker，并写入当前 Git 提交；CI 会拒绝版本未递增或文件不同步的发布。
